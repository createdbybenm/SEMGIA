# data/ – recorded samples (pseudonymized only!)

```
data/raw/sample_NNN/            # committed to Git, one folder per 24 s sample (created by record.py)
  metadata.json                 # fields = semgia/storage.py:METADATA_FIELDS
  signal.csv                    # t_s,value,label   (1 row per reading, 1 kHz → 24 000 rows)
  predictions.csv               # t_s,prediction    (live AI output, 1 row per 100 ms)
data/metadata.csv               # COURSE REQUIREMENT: one row per recording (train AND test), generated from the
                                #   metadata.json files (+ per-session constants), column `set` = train | test
data/synthetic/                 # generated by scripts/make_mock_samples.py – gitignored
```
- `label`: 0 = rest, 1 = contract, from the timer: rows 0–7999 = 0, 8000–15999 = 1, 16000–23999 = 0.
- The CSV is the FULL recording. Nobody cuts it. Transitions are skipped in code (`TRIM_S`).
- `placement_id` E01, E02, …: same number = same electrodes on the skin. New number after re-applying.
- Calibration (rest + max contraction, once per placement, from the web interface / machine):
  ```
  data/raw/calibration_E01/       # one per placement, NOT a sample (no signal.csv)
    calibration.json              # placement_id, subject_id, operator_id, start_time_utc, sampling_rate_hz,
                                  # rest_mV (mean 100 ms RMS at rest), max_mV (peak 100 ms RMS) - computed on the ESP32
    calibration.csv               # t_s,value,step  - same signal as signal.csv, step 0 prepare / 1 rest /
                                  # 2 max contraction / 3 calculating (step as seen by the browser, ±0.2 s → trim edges)
  ```
- Web interface samples/calibrations arrive as downloads (`semgia_sample_*.json`, `semgia_calib_*.json`).
  `python scripts/import_web.py` turns them into the folders above (labels from the timer, privacy check, no duplicates).
- `value` from the web interface = raw 12-bit ESP32 ADC count (0..4095, rest ≈ 2048), same as the serial path.
  `calibration.csv` uses the same counts; only `rest_mV` / `max_mV` are mV (the ESP32's own 100 ms RMS).
- Subject `P000` / operator `OP00` / placement `E00` = test recordings. Don't commit them.

## Rules
- **Every** recording stays in `data/raw/`, test sessions too (Report 1 PDF). Rejected ones are listed in
  QUALITY-REPORT.md with the reason, not silently deleted once committed.
- **Never edit raw samples.** Bad sample (electrode fell off, wrong cue followed, aborted < 24 000 rows)?
  Delete the folder **before** committing, or, if already committed, write it into MEMORY.md and exclude it.
- New samples go into `main` through a PR from a branch `name/data-<date>`.
- No names, initials, birth dates, photos or free text that identifies the person – not even in `notes`.
- Size: ~250 KB per sample, ~25 MB for 100. Plain Git, no LFS. Don't commit derived/large files.
- If the consent does not allow GitHub storage, add `data/raw/` to `.gitignore` and share via Azure only.
