## Rejection rule (fixed before any model score)
A recording is rejected if any of these is true:
- a value sits at the ADC limit: 0 or 4095 (12-bit ADC) -> clipped signal
- a value is missing (NaN) or a row is missing (gap in `t_s` larger than one sample)
- it is not from the patient P002 (one person, one muscle)
- its length is off by more than 2% from 24000 rows (24 s at 1000 Hz)

Rejected recordings stay in `data/raw/` untouched; `scripts/train.py` and `scripts/evaluate.py` skip them.
