# M04 rationale

I support our choice to store the recordings in Microsoft Azure, in a European region (belgiumcentral), in a
private storage account and with codes instead of names (P002, OP01). Muscle signals are health data, and in
Mexico the LFPDPPP treats health data as sensitive personal data, so we must keep it safe. With codes, nobody can
link a recording to a person without the paper list. My doubt: the code and the account are ready, but when I
checked, Azure was still empty. Our 59 recordings are only in GitHub and on the laptop, so we still have to upload
them before the final delivery.

Source: Microsoft. Data residency in Azure.
https://azure.microsoft.com/en-us/explore/global-infrastructure/data-residency/
